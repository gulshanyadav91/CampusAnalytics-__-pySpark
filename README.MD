# Campus Analytics using PySpark

A beginner-friendly data analytics project using **Python, PySpark, and Jupyter Notebook** to process and analyze campus data.

## Features
- Data processing and analysis using PySpark
- Aggregation and summary statistics
- Department-wise analytics
- Exporting processed data to Parquet format

## Technologies Used
- Python
- PySpark
- Jupyter Notebook
- Pandas
- Parquet

## Getting Started
1. Install Python and Java.
2. Install the required libraries:
   ```bash
   pip install pyspark pandas pyarrow
   ```
3. Open `CampusAnalytics.ipynb` in Jupyter Notebook.
4. Run the notebook cells to perform the analysis.
